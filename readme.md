# EduPredict: Student Success Predictor 🎓

## Project Overview
EduPredict is a machine learning tool designed to predict whether a student will pass or fail based on their weekly study habits and attendance. 

## How it Works
The system uses a **Random Forest Classifier** to analyze features such as:
- Weekly Study Hours
- Attendance Percentage
- Previous Academic Performance
- Access to Resources (Internet)
